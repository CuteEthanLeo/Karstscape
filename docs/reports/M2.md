# M2 汇报：石峰

## 本次完成
- **自定义密度函数 `karstscape:tower_field`**（Java）：
  - XZ 平面按格子划分；每格可能有一座峰，位置、半径、高度、外形扰动、是否带一座连体小峰，都由世界种子和格子坐标哈希得出；
  - 峰形是近乎垂直的侧壁加圆钝峰顶；
  - 越靠近区域边缘，峰越稀、越矮；遮罩低于 0.25 的地方不长峰。
- **接入方式**：在 `final_density` 里写成 `max(地形, 石峰)`，放在插值节点外面，所以侧壁是逐方块精确计算的。
- **参数**：全部在 `karst_params.toml` 的 `[towers]` 段。
- **群系改动**：去掉了峰林群系的原版雕刻器（洞穴、峡谷）。不去掉的话，它们会把石峰打出洞和悬空。
- **新增调试命令**：
  - `/karstscape find`：找最近的大块峰林，并给出航拍坐标；
  - `/karstscape check`：生成真实区块，检查接缝、浮空和确定性；
  - `/karstscape bench`：测区块生成耗时；
  - export 的 stats.json 增加了石峰统计。

## 验证结果

### 石峰形状（karst_only，1 km 见方，逐方块）

| 项 | 目标 | 实测 |
|---|---|---|
| 相对平原高度 | 40–140，少数 160 | p5 42 / 中位 79 / p95 132 / 最高 151 |
| 直径 | 12–60 | 单峰 14–62，中位 35；连体峰丛最大 128 |
| 峰间距 | 40–90 | 中位 51（p5 36 – p95 70） |
| 平原占比 | 40–65% | 66% |
| 侧壁 ≥70° | 多数 | 97% |
| 峰顶最高 | ≤ y260 | y225 |

在 Karstscape 预设、种子 1 的峰林中心测了一次：平原 63%，侧壁 ≥70° 占 82%。该区域含渐变边缘，那里的峰较矮，所以比例低于上表。

### 质量检查
- **区块接缝**：在 13×13 个真实区块里，跨区块边界的平均高差是 1.42 格，区块内部是 1.66 格，**没有接缝**。
- **浮空**：只剩一处，是原版地牢（`monster_room`）刚好生成在一座峰体内，形成一个封闭房间。除此之外没有悬空或洞。
- **真实区块与噪声地形对比**：2704 列中 0 列不一致。
- **确定性**：同一种子新建两次世界，地形哈希和统计完全相同。
- **性能**：生成 400 个区块，测两轮：

  | 预设 | 第一轮 | 第二轮 |
  |---|---|---|
  | 原版 | 43.6 ms/区块 | 42.9 ms/区块 |
  | Karst Only（全是石峰，最坏情况） | 40.7 ms/区块 | 41.5 ms/区块 |

  Karst Only 反而**快了约 5%**，预算是不能慢超过 25%。
- headless 测试：所有 profile 都是 exit 0，没有 ERROR，也没有新增 WARN。

世界类型选 **Karst Only (debug)** 时，任意种子出生点周围全是峰林。

重点看三件事：
1. 峰的形状（够不够陡、峰顶圆不圆）；
2. 高矮、胖瘦、疏密是否合适；
3. 边缘渐矮渐稀的过渡是否自然。

## 已知问题 / 需要你决定的
1. **石峰会立在河里**，把河道截断。M4 做河谷时处理：河道附近不长峰。
2. **峰体表面还是原版材质**：峰顶是草，侧壁是石头和泥土。石灰岩条带、苔藓、藤蔓、树要到 M3 才做。
3. **外形偏圆**：每座峰有 3 个随机谐波扰动半径（幅度 0.2）。如果你觉得太像“圆柱”，可以加大扰动，或者让半径随高度变化。
4. 你确认形状之前，我不进入 M3。
