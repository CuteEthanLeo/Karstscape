# M5 汇报：发布准备

## 本次完成
- **侧壁清理**：峰林群系去掉了泥土、碎石、花岗岩、闪长岩、安山岩、凝灰岩这几种装饰性矿团，它们会在侧壁上切出棕色和灰色斑块；煤、铁、铜等真正的矿石保留。

- **生产环境验证**：新增 `gradlew prodServer`，用真正的 Fabric 服务端启动器（installer 1.1.2）加载发布 jar 和正式版 Fabric API。
- **README.md**：英文加中文，写明功能、只用原版方块、只需服务端安装、只支持 26.3 + Fabric、安装方法、调试命令和已知问题。

## 验证结果
- **生产服务器**：
  - 加载了 43 个模组，打印了 `Karstscape initialized`，没有 ERROR；
  - Karst Only 世界正常生成，出生点 OK，`/locate` 和 `/karstscape check` 都能用。
- **回归测试**：vanilla、karstscape、karst_only、towers、structures 五个 profile 全部 exit 0，没有 ERROR，也没有新增 WARN。
- **侧壁外露方块**：石头 53%、安山岩 18%、凝灰岩 12%、方解石 6%、泥土 5%、苔藓 5%，花岗岩、闪长岩、碎石都是 0。
- **最终 bench**（400 区块，5 轮取中位数）：

  | | 中位数 | 各轮 |
  |---|---|---|
  | 原版 | 17.8 ms/区块 | 17.7–18.0 |
  | Karst Only（最坏情况，全是峰林） | 19.6 ms/区块 | 19.3–19.9 |

  Karst Only 比原版**慢 9.8%**，预算是 25%。
