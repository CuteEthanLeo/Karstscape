# M6 汇报：地基（加高世界、替换默认世界类型）

v0.2 的范围（写实大地形、替换默认世界、世界加高、性能预算 50%）已写进 SPEC §10。

## 本次完成
- **自定义维度类型 `karstscape:overworld`**：
  - min_y -64，height 512，建筑上限 y 447；
  - 其余字段逐字照抄原版 `dimension_type/overworld.json`；
  - 没有覆盖 `minecraft:overworld` 维度类型，所以已有存档不受影响。
- **替换默认世界类型**：生成 `data/minecraft/worldgen/world_preset/normal.json`。
  - 主世界使用上面的维度类型和 `karstscape:overworld` noise settings，并内联群系表（含峰林）。
  - 下界和末地与原版逐字一致。
  - 专用服务器默认的 `level-type=minecraft:normal` 会直接用上新地形。
- **新增 `karstscape:classic`（原版地形）**：原版 normal 预设的逐字副本，供对照和性能基准。
- **删除 `karstscape:karstscape` 预设**：它已经由默认世界取代。`karst_only` 保留，也改用加高的维度类型。
- **生成器**：
  - `karst_params.toml` 新增 `[world]` 段，包括高度、云高、深度梯度和顶部滑坡；
  - 复制的原版密度函数里，和高度绑定的常量都改由 `[world]` 计算：
    - 深度梯度延伸到整个世界高度，斜率不变；
    - 顶部滑坡；
    - 地表搜索上限。
  - 原版这些常量的数量变了，生成器会直接报错；
  - 清理过期文件的范围扩大到 `src/main/resources/data/` 和 lang。
- **Java**：
  - 新命令 `/karstscape info`，报告 noise settings、维度类型、高度范围和海平面；
  - 导出的地表扫描改为按世界实际高度（原来写死从 y 400 往下扫）；
  - `tower_field` 的参数范围放宽到新高度。
- **测试**：
  - headless：`default` profile（默认世界）取代原来的 `karstscape` profile；`vanilla` / `bench_vanilla` 改用 `karstscape:classic`；
  - 新增 `tools/tests/test_gen_worldgen.py`（10 个测试）。

## 验证结果
- 单元测试 24 个全过；`gen_worldgen.py --check` 通过。
- headless 三个 profile 全部 exit 0，没有 ERROR，也没有新增 WARN：

  | profile | 世界类型 | 关键输出 |
  |---|---|---|
  | `default` | `minecraft:normal` | `settings karstscape:overworld, dimension_type karstscape:overworld, y -64..447`；喀斯特占陆地 8.40%；出生点 OK |
  | `vanilla` | `karstscape:classic` | `settings minecraft:overworld, dimension_type minecraft:overworld, y -64..319` |
  | `karst_only` | `karstscape:karst_only` | 峰林占陆地 99.71%；出生点 OK |

- **地形形状没变**：种子 20260915 下，新默认世界的导出和 0.1.0 的 Karstscape 世界相比：
  - 24 km 和 6 km 两个范围的 height/biome/mask.png 逐字节一致；
  - stats.json 只差 noise settings 的 id。
- **classic 与原版一致**：classic 是原版预设的逐字副本，单元测试会比对；它引用的都是原版的 noise settings 和维度类型。

## 需要你看的
这一步地形外观没有变化，所以**不需要进游戏看**。如果你想确认入口：
- 新建世界时，“世界类型：默认”就是新地形；
- 按钮能切到“原版地形”和“全峰林（调试）”。

## 不确定 / 需要你决定的
- **“实验性设置”弹窗**：
  - **原因**：原版判断主世界“稳定”的条件是维度类型和群系表都是原版的。我们两者都是自定义的，所以单人模式下新建和打开世界时会弹确认框。
  - 0.1.0 的 Karstscape 世界类型已经是这样；替换默认世界后，每个新世界都会弹。
  - 专用服务器不受影响。
  - 去掉弹窗需要加一个只在客户端生效的 mixin。我打算放到 M10 做，你如果想更早去掉，告诉我。
