# M3 汇报：材质、植被、雾

## 本次完成
所有新内容仍然由 `tools/worldgen/karst_params.toml` 生成，对应 `[material]`、`[vegetation]` 两段和 `[biome]` 段的雾与颜色参数。

### 峰体材质（material rule，只作用于峰林群系）
- **侧壁**：按高度分水平条带，模仿石灰岩层理。条带用石头、安山岩、方解石、凝灰岩、滴水石块，每条 2–7 格厚，排列固定不变。侧壁上还有一些苔藓块斑块，由 3D 噪声决定。
- **峰顶**：草方块为主，夹杂苔藓块，表层下面是泥土；峰顶边缘的陡坡用条带石材。
- **峰脚**：y80 以上的陡坡地面铺碎石或粗泥。
- **河床、湖底**：水下表面按噪声铺黏土、沙子或碎石。
- **平原**：仍用原版草地和泥土。

### 植被（全部是原版地物）
- **保留平原原有的**：草、花、零星的树、甘蔗、南瓜等。
- **新增**：
  - 杜鹃树、丛林灌木：峰顶和平原都会长；
  - 竹子；
  - 小水塘；
  - 侧壁藤蔓：在 y66–240 之间生成。
- **去掉**：地牢、地表和地下熔岩湖。它们会在峰体里掏出空腔，上一轮 check 发现的那个“封闭房间”就是熔岩湖造成的。

### 雾与颜色
- 雾色改成淡白蓝 `#d3e1ee`，天空颜色稍浅，用的是 26.3 的群系环境属性 `visual/*`。
- 水的颜色偏青绿。

## 验证结果
- **headless 测试**：towers、karstscape、vanilla 三个 profile 都是新建世界，exit 0，没有 ERROR，也没有新增 WARN。
- **真实区块方块统计**（Karst Only，13×13 区块，种子 20260915）：
  - 侧壁外露方块：石头 49%、安山岩 16%、凝灰岩 10%、方解石 7%、泥土 7%（来自峰顶边缘）、苔藓块 5%；
  - 峰顶：草方块 71%、苔藓块 14%；
  - 植物方块：杜鹃树叶约 1.5 万、藤蔓 5695、橡树叶 5086，另有草、花、竹子；
  - 峰体内空腔：**0**（加植被前有 85 列，原因是地下熔岩湖，已去掉）；
  - 区块接缝：没有。跨区块边界的平均高差 1.42 格，区块内部 1.66 格。
- **性能**：生成 400 个区块，原版 44.1 ms/区块，Karst Only 50.2 ms/区块，慢了 13.7%，在 25% 的预算内。M2 时 Karst Only 还比原版快 5%，多出来的耗时主要来自藤蔓（每区块尝试 2500 次）和新增的树。

世界类型选 Karst Only 时，任意种子出生点周围都可以看。

看五件事：
1. 侧壁的条带是否像石灰岩层理；
2. 苔藓、藤蔓够不够；
3. 峰顶的树和杜鹃丛；
4. 雾的浓淡和颜色，远处的峰是否分出层次；
5. 河床、湖底的材质。

## 不确定 / 需要你决定的
1. **雾距离没调**：原版群系里只用过雾的颜色，雾距离这个属性只在下界的维度设置里出现过，群系里写它能不能生效没有把握。这次只改了雾的颜色。如果你觉得雾太淡，我再试群系级的雾距离。
2. **藤蔓是单格的**：原版藤蔓地物每次只放一格，不会成串往下垂。如果你想要垂挂的长藤，需要另写一个地物，要用 Java。
3. **峰顶边缘的侧壁会露出泥土**（约占侧壁的 7%），因为峰顶草皮下面那几格泥土在穹顶边缘会露在侧面。可以改成只在平缓处铺泥土。
4. **石峰仍然会立在河里**，这是 M4 的内容。
