# M4 汇报：可玩性（河流、结构、出生点）

## 本次完成

### 河流
原版河流走在 weirdness（`ridges`）接近 0 的地方。在峰林遮罩内做了两件事：
- **河道**：|ridges| < 0.03 的范围是河床，目标 y58，实际落在 y59 左右；往外 0.05 是缓坡河岸，逐渐升到平原。河道范围内河床不会比 y58 更深，所以是**宽、浅、能划船**的河谷。走廊以外的湖保留原深度。
- **河道走廊不长峰**：|ridges| < 0.12 的地方不放峰心，0.12–0.16 之间逐渐恢复。石峰因此不会截断河流。
- 参数在 `karst_params.toml` 的 `[river]` 段。

### 结构
- 峰林群系只加入了**地下结构**的群系标签：废弃矿井、要塞、试炼密室，以及 `is_overworld`。
- **地上结构不进峰林**：村庄、掠夺者前哨站、废弃传送门、营地等。规格允许遇到问题时用群系标签排除。理由有两个：
  1. 落在峰顶或峭壁上；
  2. 原版的地形适配（beardifier）会把结构的占地挖进峰体侧壁。
- karst_only 原先在海岸留了一条非峰林的窄带，实测村庄就挤在那条带上，64 格内有 9–83 个石峰采样点。现在把 karst_only 的峰林范围扩到海岸（大陆性 ≥ -0.19），这条窄带不再存在，4 个种子附近都找不到村庄。

### 出生点
- **Karstscape 预设**：原版出生点搜索范围扣掉了喀斯特参数盒，所以出生点不会选在峰林里。
- **karst_only**：出生点搜索限定在最外侧的海岸带（大陆性 -0.19 到 -0.18）。那里遮罩低于 0.25，不长峰。

### 新增调试命令
- `/karstscape spawn`：检查世界出生点；
- `/karstscape probe <x> <z>`：检查某一列是否站在峰体上、是否嵌在地形里，以及周围 64 格内有多少石峰；
- export 统计新增两项：贴水的峰体采样点数、核心区的水深。

### 性能
- 峰体条带的材质规则改成二分式嵌套判断，每个方块大约判 6 次，原来最多 40 次。
- 侧壁苔藓从 3D 噪声改成 2D 噪声，每列只算一次，外观是竖向苔藓条纹。
- 藤蔓尝试次数从 2500 降到 1200。

## 验证结果

### 河流（karst_only，1 km 逐方块，种子 20260915）
- 河道里没有石峰。只剩 37 个峰体采样点贴着水，都在湖边或水塘边，不在河道中。
- 核心区水深：中位数 2 格，p95 6 格（含湖泊）。改之前中位数是 6 格。
- 代价：平原占比从 66% 升到 71%，因为河道走廊算作平原。

### 结构
- **karst_only，4 个种子**：附近找不到村庄；废弃矿井在 68–256 格内，试炼密室在 208–430 格内，都能正常生成。
- **Karstscape，种子 1**：峰林附近最近的两个村庄分别在 (4208, -3088) 森林和 (2016, -3008) 热带草原，64 格内都没有石峰。

### 回归测试
- vanilla、karstscape、karst_only、towers 四个 profile：exit 0，没有 ERROR，也没有新增 WARN。
- 峰体内空腔 0。
- 没有区块接缝：跨区块边界的平均高差 1.06 格，区块内部 1.07 格。
- 侧壁外露方块：石头 51%、安山岩 18%、凝灰岩 11%、方解石 6%、苔藓 5%。

### 性能（400 区块，机器上同时有其他 Java 程序，波动较大）

| | 测量值（ms/区块） | 中位数 |
|---|---|---|
| 原版，5 轮 | 18.0–18.6 | 18.1 |
| karst_only，5 轮 | 20.7–25.1 | 21.0 |

karst_only 比原版慢约 **16%**，预算是 25%。karst_only 是石峰最多的最坏情况。

## 需要你看的
世界类型选 **Karstscape**：
- **种子 1**：`/tp @s 2848 210 -2048 -138 25`。找一条穿过峰林的河，放船顺流划一段，看能不能一路划通、有没有被石峰挡住。
- **任意种子新建世界**：确认没出生在峰顶上。

## 不确定 / 需要你决定的
1. **峰林里没有村庄**（包括正常的 Karstscape 预设）。如果你希望峰林平原上也有村庄，需要做“村庄周围不长峰”的处理。这要用 Java，在石峰生成时避开结构，工作量中等，可以留到 v0.2。
2. **河道走廊按原版河流的 weirdness 定位**，所以只有原版本来就有河的地方才有宽河谷。峰林里额外的小溪、湖泊目前没有。
3. **karst_only 的海岸带也变成了峰林**，这是你上次提的选项 3。出生点在最外侧那一窄条海岸上。
