# M8 汇报：山脉、河谷、台地、海岸悬崖

## 本次完成
所有改动都是数据，由 `gen_worldgen.py` 生成到 `karstscape:terrain/*`，参数在 `karst_params.toml` 的 `[terrain.*]` 和 `[noises.*]` 段。

- **去掉环形山**：原版 weirdness 折叠后，在 |ridges| > 2/3 的地方地形会再往下落，于是山峰绕着中间一圈洼地分布，像火山口。现在超过 2/3 之后保持峰顶高度不再下落。
- **连绵山脉**：在山区，weirdness 的大小改由一个山脊噪声决定，其中 crest = (1 − |n|)²：
  - 脊线上是峰，脊线之间是谷，山峰因此沿着长而弯曲的脊线排成山脉，不再是一个个平顶圆包；
  - 山区的范围按 erosion 和 continentalness 判断，与原版判断“山地”的条件一致；
  - 河流所在的 weirdness≈0 附近保留原值，所以河流照样穿山而过；
  - 群系、河谷、峰林避让都读这同一个值，所以山峰群系、河流群系会跟着新的脊线走；
  - 脊线上另外再加 40 格的高度。
- **河谷和峡谷**：所有河流（|ridges| < 0.015）都切到 y 58，水面在海平面 63。
  - 河道两侧按 V 形升高：|ridges| 每增加 0.12，岸壁升高 320 格，形状是 1.5 次方曲线。
  - 平原上是普通河岸；流经高地时切成深峡谷。
- **台地**：在一个独立噪声选出的丘陵区（不在山区）把地形做成阶梯：
  - 每级 20 格，台面基本平整，陡坎约占每级水平宽度的 30%；
  - 台地区的 factor 提到 8，减少 3D 噪声，让台面更平、陡坎更干净。
- **海岸悬崖**：在噪声选出的约一半海岸，陆地在岸线处整体抬升 28 格，向内陆逐渐消失。实际效果是：岸边先有一条低矮的平台，然后是一道陡壁。
- **高度平衡**：
  - offset 曲线的顶端从 340 降到 280；
  - jaggedness 回到原版的 ×1.0；
  - 顶部滑坡移到 y 424..446；
  - 单元测试保证“基础最高点 + 一道满高度的脊线”低于滑坡起点，山顶不会被削平。
- **调试工具**：
  - 新命令 `/karstscape layer <半径> <x> <z> <步长> <密度函数 id>`：把任意密度函数（例如 `karstscape:terrain/mountains`）导出成灰度图和统计，headless profile 是 `layers`；
  - 导出的 stats.json 新增 `rivers` 段：河道中心是否是水、地表是否超过 y 64。
- **单元测试**：30 个，全过。新增一项检查：生成的数据里引用的每个 `karstscape:` id 都有对应的文件。

## 需要你看的
新建世界，类型保持“默认”，种子填 **20260915**。进去后切创造模式。

| 看什么 | 命令 | 说明 |
|---|---|---|
| 山脉 | `/tp @s 850 300 -700 -59 5` | 出生点东北方向一条南北走向的长山脊，主峰在 (1256, -452)，y 314 |
| 峡谷 | `/tp @s 950 200 -1275 -90 20` | 一条河从西往东横穿上面那条山脉；沿河往东飞 |
| 最高的山 | `/tp @s 2764 400 2452 -135 10` | 峰顶 (3064, 2152)，y 375 |
| 台地 | `/tp @s -1152 200 -1200 180 25` | 往北看，一级级的阶梯状丘陵 |
| 海岸悬崖 | `/tp @s -2816 110 -1050 180 5` | 往北看那座岛：岸边一条低平台，后面是 20 多格高的陡壁 |

请判断：
1. 山脉是否够“连绵”，脊线的长短和弯曲程度合不合适；
2. 峡谷的深度、宽度和陡度；
3. 台地和悬崖是否明显、是否太多或太少。

## 不确定 / 需要你决定的
- **干河床**：河道中心有 7–19% 的采样点是低于海平面、却没有水的干河床。原因是含水层没有把这些地方灌到海平面。你如果在游戏里看到断流的河段觉得别扭，我在 M9 处理。
- **群系和地形对不上的地方**：weirdness 改成跟着脊线走以后，原版的山峰群系（尖峭山峰、冰封山峰等）也跟着脊线走；但台地和悬崖是独立噪声生成的，所在位置的群系不会专门配合，例如悬崖顶上可能还是沙滩群系。M9 做表层材质时会让陡壁露出石头。
- **性能**：慢 37%，还在预算内。M10 我会再看看能不能优化。
